# Hivo in French and English

The desktop app is in **English and French** (Settings → Language: System, Français, English). The website follows the page language (/fr, /en, else the browser): the landing has its own copy (`web/src/landingCopy.ts`), the signed-in crew dashboard uses `web/src/dashboardCopy.ts` with the same `dict`/`tr` system.

## How it works (src/i18n)

```ts
import { dict, plural, tr } from "../i18n";

const T = dict(
  { title: "Releases", songs: (n: number) => `${n} ${plural(n, "song", "songs")}` },
  { title: "Sorties", songs: (n: number) => `${n} ${plural(n, "son", "sons")}` },
);
// in a component or a plain helper:
tr(T).title; tr(T).songs(3);
```

- One dictionary per file (or per area), next to the code that uses it, named `T` (or `T_SOMETHING`).
- English is the reference. TypeScript refuses a French dictionary with a missing key or a different function signature.
- Changing the language remounts the whole app (App.tsx keys the root on it): call `tr()` anywhere, no hooks needed. Don't cache translated text in module-level constants (they'd keep the first language). Stage names (`STATUSES`, `UNSORTED`, `statusInfo`) are already translated; spreading `...UNSORTED` copies the words, so only do it where it's shown.
- Dates and sizes: `formatRelative`, `formatDate`, `formatDateTime`, `formatBytes`, `trashName()` follow the language. For other `toLocale*` calls pass `locale()`.
- Plurals and word order: use functions (`(n) => ...`), never glue translated fragments together. Pick the form with `plural(n, one, other)` (Intl.PluralRules: French singular for 0 and 1, English for 1 only), never `n === 1` or `n > 1`. The phone has the same helper in `mobile/src/lib/i18n.ts`.
- Errors from Rust: a command fails with a coded error (`src-tauri/src/error.rs`: `app_err(code, english_detail).with(param, value)`), translated by `src/lib/errors.ts`. Show `errorText(e)` (or `errorReason(e)` inside a sentence that already says what failed); `errorDetail(e)` is the raw English. A new code needs its English and French sentence there (a Rust test checks it).
- Don't translate: data (song titles, names, tags, keys like "Am", file names, paths), brand and product names (Hivo, Launch Kit, FL Studio, Ableton Live, Gemini, ffmpeg, Supabase), error text that comes from the system and is shown raw.

## French style

- Casual **tu** everywhere (the crew's voice, like the landing page). Short, plain sentences.
- Typography: a narrow no-break space (U+202F) before `?` `!` `:` `;` and inside « ». Straight apostrophes are fine. `src/i18n/typography.test.ts` reads every French dictionary (desktop, website, phone) and fails on a plain space there.
- Gender-neutral: no "connecté", "seul", "le dernier membre" about the reader; rephrase ("Ta session est ouverte", "sans crew", "Il ne reste que toi").
- Buttons stay short: infinitive (« Partager », « Exporter ») or a noun.
- Keep the System 02 feel: uppercase is done by CSS, so write normal case.
